# Water Level Sensor

## Overview
This project demonstrates a Water Level Monitoring System using Arduino Uno and Tinkercad simulation. The system indicates different water levels using LEDs and activates a buzzer when the tank reaches a high level.

## Features
- Water level monitoring
- LED indicators for low, medium, and high levels
- Buzzer alert for full tank
- Arduino-based implementation
- Tinkercad simulation

## Components Used
- Arduino Uno
- LEDs
- Buzzer
- Resistors
- Breadboard
- Jumper Wires

## Technologies Used
- Arduino
- Tinkercad
- Embedded Systems

## Applications
- Household water tanks
- Industrial water storage systems
- Water conservation and monitoring
